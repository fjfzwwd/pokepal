# PokePal · 宝可梦桌面宠物

一个可以养在桌面上的宝可梦电子宠物：可以拖动抛投、会自己散步、饿了会闹、
逛够能升级进化、还能去打工赚零花钱；可以**去草丛探险、投球捕捉**野生宝可梦，
同伴多了可以**寄存进 BOX 仓库**；另外附带一只同样会随时间成长的「蚕」，
用来验证一个设计原则——**万物皆实体**。

纯 Python + tkinter，**零第三方依赖**即可运行（Pillow 可选）。
桌面悬浮窗基于 Windows 的 `transparentcolor`，透明无边框、置顶、可直接落在图标之上。

---

## 1. 同类项目调研

调研了 GitHub 上一批桌面宠物项目，结论如下：

| 项目 | 技术栈 | 值得借鉴的点 |
| --- | --- | --- |
| `duzexu/desktop-pet` | Electron | `.petpack` 素材包、条件/动作/优先级的交互规则编辑 |
| `kami1457/DesktopPet` | HTML / Electron | 拖拽抛投物理、饱食度与心情系统、番茄钟 |
| `BernaTameirao/desktop-pet`（Deskmon） | Electron | 直接做成了宝可梦：内置第一代作为宠物 |
| `CGG-TYPES/dsh-piggy` | Electron 插件 | 完整的电子宠物循环：成长 / 学习 / 打工 / 钓鱼 / 图鉴 / 换肤 |
| `isKage/desk-llm-pet` | Electron | 透明通道 WebM 素材 + 动画池随机播放 |

共性可以提炼成三条：

1. **桌面宠物本体 = 透明无边框置顶窗口 + 逐帧素材**
2. **可玩性来自“数值随时间衰减 + 玩家投入照顾”的电子宠物循环**
3. **留存来自“图鉴收集 + 分工不同的活动（打工 / 学习）”的 QQ 宠物循环**

本项目的实现选择了和它们不同的路线：不做 Electron（本机无 Node），
用 Python 标准库 `tkinter` 直接做出同等效果，依赖为零。

## 2. 设计原则

### 2.1 万物皆实体

一句约束：**任何有价值的存在，都应该是一圈独立的东西——它由自己的状态驱动、
有可以被施加的行为、并且应该在界面上被看见。**

在本项目里落实成：

| 实体 | 自身状态 | 可施加的行为 | UI 呈现 |
| --- | --- | --- | --- |
| 宝可梦 `Pet` | 等级/经验、五维数值、羁绊、当前活动、在队伍还是寄存 | 喂食、喝水、清洁、玩耍、训练、睡觉、打工、进化、寄存 | 桌宠本体 + 状态卡 + 面板「状态 / 仓库」页 |
| 一次相遇 `Encounter` | 物种、等级、放松程度、回合数、是否已逃 | 投喂树果、投精灵球、悄悄离开 | 「野外相遇」窗口 + 探索日志 |
| 蚕 `SilkWorm` | 生命周期阶段、成长度、饥饿、脏污、存活 | 投喂桑叶、清扫蚕室、采收蚕丝 | 面板「蚕室」页，由桌宠转告进度 |
| 道具 `Item` | 类别、价格、效果表、球倍率 | 购买、使用、作为进化 / 捕捉媒介 | 面板「养育 / 商店」页 |
| 图鉴条目 `DexEntry` | 已收服 / 已见过 / 未发现、属性、进化条件 | 查询、收养 | 面板「图鉴」页（未相遇显示为 ？，悬停看详情） |

因此宝可梦不是「兑换物」，而是**从图鉴里遇到、捕捉后收进来的一只实体**；
一次相遇也不是函数调用，而是一个会警惕、会被引诱、会逃跑的状态机；
蚕不是道具，而是一个会饿、会脏、会死、也会吐丝的生命体。
以后要加"钓鱼 / 牧场 / 咖啡店"，照抄这套结构即可。

### 2.2 三个循环

```
        照顾投入                时间流逝
   ┌──────────────────────────►  数值衰减  ──┐
   │                                          │
   │   ▼                                      ▼
 人情反馈（羁绊/心情）  ◄────  状态判定  ────►  诉求（气泡台词）
                             │
                             ▼
                    打工/训练 → 零花钱 + 经验 → 升级 → 进化
```

## 3. 目录结构

```
PokePal/
├─ main.py                 入口：App 编排 + 右键菜单 + 主定时器
├─ assets/
│  ├─ gifmeta.py           零依赖 GIF 逐帧延时解析（直接读文件字节流）
│  └─ sprites.py           多镜像下载 → 本地缓存 → 逐帧拆解 → 缩放
├─ core/                   纯逻辑，不碰 tkinter
│  ├─ dex.py               图鉴数据访问、进化条件判定、临时联网查询
│  ├─ items.py             道具表（食物/饮品/清洁/玩具/药品/精灵球/进化石/补给/材料）
│  ├─ pet.py               状态机：五维衰减、活动、经验和进化
│  ├─ encounter.py         野外相遇实体：遇怪权重、捕捉率、回合与逃跑
│  ├─ farm.py              实体化示例：蚕的生命周期
│  └─ store.py             存档、钱包、背包、队伍/BOX、探索记录
├─ ui/
│  ├─ widgets.py           共用组件：数值条、滚动容器、配色
│  ├─ window.py            桌宠窗口：物理、AI、气泡、特效
│  ├─ panel.py             主控面板：状态/养育/商店/图鉴/探索/仓库/蚕室/设置
│  ├─ encounter.py         「野外相遇」窗口
│  ├─ dock.py              功能图标台：无边框小框 + 图标按钮
│  └─ phrases.py           台词库
├─ data/dex.json           由图鉴生成脚本产出（105 只：进化链 + 传说/幻之）
├─ tools/                  开发脚本（生成图鉴 / 图标与快捷方式 / 各类冒烟测试）
└─ run.bat                 Windows 双击启动
```

数据流：`main.App` 每秒 tick → `core` 结算 → 结果驱动 `ui.window` 的画面与台词；
所有 UI 操作反过来调用 `core` 的行为方法，**不存在 UI 里写数值逻辑**的情况。

## 4. 养成模型

五维数值 0~100，随时间下降（睡觉时走另一套衰减率，体力反而会恢复）：

| 数值 | 每小时衰减 | 主要来源 |
| --- | --- | --- |
| 饱食度 | 6.0 | 橙橙果 / 文柚果 / 宝芬 |
| 水分 | 7.5 | 矿泉水 / 哞哞牛奶 / 柠檬水 |
| 清洁度 | 4.5 | 毛巾 / 泡泡浴球 / 沐浴露 |
| 心情 | 5.0 | 玩具，同时被其他低数值拖累 |
| 体力 | 4.0 | 睡觉；训练与打工消耗 |

- **羁绊** 只升不降（冷落时会缓慢掉），是进化条件与"亲密度"的度量。
- **离线结算**：下次启动时会一次性结算离开这段时间（上限 24 小时），
  所以它真的会像电子宠物那样"饿着等你回来"。
- **状态判定**：`健康 / 饿 / 渴 / 脏 / 累 / 低落 / 一般 / 很好`，驱动心情台词与外形提示。

### 活动状态机

```
 idle ──喂食──► eat(4s) ──┐
      ──玩具──► play(5s) ─┤
      ──清洁──► bath(5s) ─┼──► idle
      ──训练──► train(6s)─┤
      ──进化石► evolve ───┘
      ──睡觉──► sleep（手动唤醒 / 体力回满自动醒）
      ──打工──► work（后台 5/15/30 分钟，回来自动结算工资）
```

### 成长：经验 → 等级 → 进化

经验来自训练（12~25 点）、玩具、各种照顾行为、以及打工。
升级所需经验随等级递增，100 级封顶。

### 获得：探索 → 相遇 → 捕捉

桌宠里没有「对战」，所以把削弱改成了**投喂诱导**：

```
出发探索（75 秒冷却）
   └─ 按权重抽一只野生宝可梦（初级形态更常见，传说 2%）
        ├─ 投喂树果 → 放松程度 +
        ├─ 投精灵球 → 成功率 = 种族捕获度 × 等级系数 × 阶段系数 × 放松程度 × 球倍率
        │              （大师球必中；每次失手它更警觉）
        └─ 最多 8 个回合，它随时可能跑掉
```

| 球 | 倍率 | 参考价格 |
| --- | --- | --- |
| 精灵球 | 1.0x | 200 |
| 超级球 | 1.5x | 600 |
| 高级球 | 2.0x | 1200 |
| 大师球 | 必中 | 20000 |

收服后它带着相遇时的等级加入你，**队伍满 6 位**时会自动寄存到 BOX 仓库——
仓库里的形态、等级、羁绊、获得途径全都看得见，随时可以接回来同行。

进化条件直接由 PokéAPI 的 `evolution_details` 解析而来，三种触发都支持：

- **等级达到**（妙蛙种子 16 级 → 妙蛙草）：满足条件自动进化
- **使用进化石**（皮卡丘 → 雷丘）：商店买石头，右键菜单手动使用
- **羁绊达标 / 白天夜晚**（伊布 → 太阳伊布 / 月亮伊布）
- 分支进化（伊布 8 种去向）会在菜单里列出来让玩家自选

## 5. 桌宠交互

| 操作 | 结果 |
| --- | --- |
| 单击 | 抚摸，提升羁绊与心情（有 45 秒防刷冷却） |
| 双击 | 打开主控面板 |
| 中键 | 弹出功能图标台（12 个图标，点一下直接执行） |
| 右键 | 快捷菜单：喂食/喝水/清洁/玩耍/训练/睡觉/打工/进化/去探险/同伴与 BOX/设置/退出 |
| 拖动 + 松手 | 抛物线下落，触地按 0.42 系数反弹直到静止 |
| 什么都不干 | 自己散步、回头看、随机说话、夜间自动睡觉 |

主控面板共 8 个页签：**状态 / 养育 / 商店 / 图鉴 / 探索 / 仓库 / 蚕室 / 设置**。
图鉴会用绿框标记「已收服」、蓝框标记「只是见过」，未相遇的显示 ？ 且不剧透属性说明。
新存档的起始零花钱是 **1,000,000 元**（老存档在升级时一次性补足，已有的更多则不动）。

### 沙盒：一键全开

「设置 → 沙盒 → 一键全开」或右键菜单「一键全开（沙盒：全图鉴 + 满级）」：

- 所有图鉴条目一次点亮（`met` / `caught` 全量写入）
- 每一只宝可梦都以 **Lv.100** 加入你，同行仍限 6 位，其余自动进 BOX（实测 105 位：同行 6 + 仓库 99）
- 已有伙伴也一起拉满等级，操作约 0.1 秒完成（页签是懒重建的，不会卡）

适合想直接看全部内容的时候；它会改写当前存档，介意的话先备份 `save.json`。

### 功能图标台

右键菜单里藏着一大堆操作，一个个翻太慢；**中键点一下桌宠**（或右键菜单第一项
「功能小框」）会弹出一个无边框小框，把常用功能摊成 12 个图标：

```
面板  喂食  喝水  玩耍  训练  睡觉
打工  探险  图鉴  仓库  蚕室  设置
```

- 图标是「彩色圆角方块 + 汉字」，不依赖图片素材，任何 DPI 下都清晰
- 点一下就执行：喂食 / 喝水 / 玩耍自动挑背包里最好的那个道具，打工默认 15 分钟
- 鼠标移开 0.9 秒自动收起，`Esc` 关闭，也可以按住空白处把它拖到别处
- 只有卡片那块是实心的，四周透明且鼠标穿透（`-transparentcolor`）

想加功能就往 `App.dock_entries()` 的列表里补一行 `(名字, 汉字, 底色, 回调)`。

因为使用了 `transparentcolor`，精灵以外的区域**鼠标可以穿透**，
不会挡住桌面上的图标和其他窗口。

## 6. 素材方案

优先级三档自动降级，任取其一即可显示：

1. **第五世代黑白动画 GIF**（PokeAPI sprites）——像素风、帧数多、体积小，首选
2. **Pokémon Showdown 动画 GIF**——覆盖到第九世代
3. **官方静态 PNG**——网络极差时的保底

- 镜像顺序：`raw.githubusercontent` → `cdn.jsdelivr.net` → `fastly.jsdelivr.net`
- 下载结果写入 `%USERPROFILE%/.pokepal/sprite_cache/`，第二次打开离线也能显示
- 无 Pillow 时会退化到 `tkinter.PhotoImage` 的 `gif -index` + 整数倍 zoom

## 7. 快速开始

```bash
python main.py          # 或者 Windows 下双击 run.bat
python -m pip install Pillow   # 可选，画质更好
```

### 桌面快捷方式

```powershell
python tools/make_icon.py                 # 用皮卡丘素材生成 assets/app.ico（可选）
powershell -ExecutionPolicy Bypass -File tools/install_shortcut.ps1
powershell -ExecutionPolicy Bypass -File tools/install_shortcut.ps1 -StartMenu   # 同时加到开始菜单
```

脚本会自动挑可用的 `pythonw.exe`（项目虚拟环境优先，退到系统 Python），
生成的 `PokePal · 宝可梦桌宠.lnk` 指向 `main.py`、起始位置为项目根目录，
并用 `assets/app.ico` 当图标——双击启动**不会有黑色控制台窗口**。

首次启动会自动下载精灵图（约几百 KB），之后全部走本地缓存。
图鉴数据是仓库里已经生成好的 `data/dex.json`（105 只：进化链 + 传说/幻之），
需要更新时用：

```bash
python tools/fetch_dex.py
```

存档位置：`%USERPROFILE%/.pokepal/save.json`

开发期自检脚本：

```bash
python tools/smoke_core.py    # 养成核心：衰减 / 离线结算 / 进化 / 经济
python tools/smoke_farm.py    # 蚕室：成长 / 饥饿死亡 / 结茧采收 / 存档
python tools/smoke_catch.py   # 遇怪分布 / 捕捉率 / BOX 仓库
python tools/smoke_run.py 12  # 整机 GUI（会自动开关面板并打印报告）
```

## 8. 已知限制与后续路线

- Windows 优先：`transparentcolor` 是 Windows Tk 的特性，macOS/Linux 需要换成别的透明方案
- 没有系统托盘图标（零依赖的代价），控制全靠桌宠右键菜单
- 待办方向：开机自启动、番茄钟、眨眼/摇尾巴等更细的触控反馈动画、
  更多实体（钓鱼 / 牧场 / 咖啡店）、自定义素材包导出
- 若将来要做 Live2D / WebM 透明视频版本，建议把 `assets/sprites.py`
  换成 Electron + `<video>` 实现，`core/` 的养成逻辑可以原样复用
